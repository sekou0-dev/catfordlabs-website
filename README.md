# Catford Labs

Public homepage for Catford Labs — games and apps for the world’s markets.

Drop a logo into `assets/mark.svg` (and `favicon.svg`) when it is ready. Copy on the page is a starting point and can be replaced later.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## GitHub Pages

This repo is set up as a static site at the root. In GitHub: **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
